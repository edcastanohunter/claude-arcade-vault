@AGENTS.md

## Project

Arcade Vault: a platform for playing games online and competing for high scores (see README.md). The repo is currently a fresh `create-next-app` scaffold (App Router, TypeScript, Tailwind v4) — `app/page.tsx` and `app/layout.tsx` are still the default template content, no game logic exists yet.

## Commands

- `npm run dev` — start the dev server (Turbopack)
- `npm run build` — production build
- `npm run start` — run the production build
- `npm run lint` — ESLint (flat config via `eslint-config-next`)

There is no test runner configured yet.

## Architecture notes

- Next.js App Router under `app/`, path alias `@/*` maps to the repo root (see `tsconfig.json`).
- Tailwind CSS v4 via `@tailwindcss/postcss` (`postcss.config.mjs`), styles in `app/globals.css`.
- **Read `AGENTS.md` before writing any code** — this project pins a Next.js version whose APIs/conventions may diverge from training data; the docs at `node_modules/next/dist/docs/` are the source of truth, and that file is regenerated by `next dev` so don't fight the diff.

## Workflow

Per README.md, this project follows Spec Driven Design using `/spec` and `/spec-impl`, based on the practices/skills from https://github.com/Klerith/fernando-skills (installed via `npx skills@latest add Klerith/fernando-skills`). `docs/promp-arcade-vault.md` is the intended spec/prompt doc for the project but is currently empty.
